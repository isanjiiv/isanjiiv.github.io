# Repository Documentation

This folder contains documentation about the structure and maintenance of the portfolio site.

## Current site structure

- `index.html` — primary homepage
- `about.html` — About page
- `services.html` — IT services page
- `assets/` — images, documents, and audio used by the site
- `robots.txt` — crawler rules
- `sitemap.xml` — XML sitemap
- `other-files/` — preserved legacy/draft HTML, CSS, JavaScript, and earlier versions

## Preservation policy

Existing files are intentionally preserved. The archive/legacy area is retained for historical reference and is not part of the primary site navigation unless explicitly linked.

## Maintenance guidance

Keep production pages at the repository root so existing URLs remain stable. Add new static assets under `assets/` using descriptive subfolders. Keep experimental or superseded versions under `other-files/` or another clearly labeled archive area.
